308-07A Four Wheel Drive (4WD) Systems 2013 F-150
Removal and Installation Procedure revision date: 08/30/2012

Mode Select Switch (MSS)


Item Part Number Description
1 14B16614B166 Mode Select Switch (MSS)
2 — MSS electrical connector (part of 14401)

  1. Carefully pry the Mode Select Switch (MSS) from the instrument panel.
  1. Disconnect the MSS harness connector and remove the switch.
  1. To install, reverse the removal procedure.
