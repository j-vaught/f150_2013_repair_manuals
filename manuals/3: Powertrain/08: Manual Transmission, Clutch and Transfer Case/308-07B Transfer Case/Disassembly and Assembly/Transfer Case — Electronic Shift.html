Disassembly

NOTE: Discard all seals after removing them.

  1. Clean the transfer case with solvent and dry with compressed air.
  1. Using the Transmission Holding Fixture, secure the transfer case to the bench.
  1. Remove the rear output shaft seal.
  1. Remove the inner connector retainer. Press the release tab and remove the coil wire from the electric shift motor electrical connector.
  1. Remove the 3 transfer case shift motor bolts, bracket bolt and loosen the 2 bracket nuts.

  1. NOTE: The transfer case bolts are self tapping, and it is normal to find metal shavings while removing the cover.

    Remove the 20 transfer case bolts.
  1. Using the pry bosses, separate the transfer case covers.
  1. Remove the 3 transfer case field coil nuts, washers and transfer case field coil.
  1. Using the Bearing Cup Remover with the Slide Hammer, remove the rear output shaft bearing.
  1. Using the Bearing Cup Remover with the Slide Hammer, remove the front output shaft bearing.
  1. Remove the shift collar hub snap ring.
  1. Remove the coil housing.
  1. Remove the shift fork.
    1. Remove the lockup hub.
    1. Remove the shift fork and spring.

  1. NOTE: Remove the lockup hub assembly as a single unit. If disassembly is required, proceed with the following.

    Disassemble the lockup hub assembly.
    1. Remove the lockup hub snap ring.
    1. Separate the lockup collar.
    1. Separate the 2 lockup springs.
    1. Separate the lockup hub.
    1. Remove the armature.

  1. NOTE: Remove the drive chain and sprockets as an assembly.

    Remove the drive chain, sprockets and the thrust washer.
  1. Remove the magnet from its slot in the case.

  1. NOTE: The pump assembly is not repairable.

    Remove the oil pump and the output shaft as an assembly. Remove the oil pump from the output shaft.
  1. Remove the shift rail.
  1. Remove the shift fork and the reduction hub.
    1. Remove the shift fork.
    1. Remove the reduction hub.

  1. NOTE: The electric shift cam is serviced as an assembly. Do not disassemble the shift cam assembly.

    Remove the electric shift cam assembly.
  1. Remove the front planet carrier.
  1. Remove and discard the front input shaft seal.
  1. Remove the thrust bearing.
    • Remove the needle bearing, if necessary.
  1. Remove the ring gear.
    1. Remove the ring gear snap ring.
    1. Remove the ring gear.
  1. Using the Stator Bearing Remover with the Slide Hammer, remove the front planet carrier bearing.
  1. If equipped, remove the driven sprocket spacer.

  1. NOTICE: Do not let the front output shaft fall while removing the snap ring or damage to the component may occur.

    Remove the front output shaft.
    1. Remove the front output shaft snap ring.
    1. Remove the front output shaft.
  1. Using the Stator Bearing Remover with the Slide Hammer, remove the front output shaft bearing.
  1. Using the Bearing Cup Remover with the Slide Hammer, remove the front output shaft seal.

Assembly

  1. Using a press and the Bearing Cup Installer with the Handle, install the front output shaft bearing.
  1. Using the Input Shaft Oil Seal Installer, install the front output shaft seal.
  1. Install the front output shaft.
    1. Position the front output shaft.
    1. Install the front output shaft snap ring.
  1. If equipped, install the driven sprocket spacer.
  1. Install the front planet carrier bearing.
  1. Using the Input Shaft Oil Seal Installer, install the front input seal.
  1. Position the ring gear in the case. Install the ring gear snap ring.
  1. If removed, using a press and the Input Shaft Bearing Installer, install the needle bearing into the front planet carrier.
  1. Install the front planet carrier and the thrust bearing.
  1. Install the electric shift cam assembly.
  1. Install the shift fork and the reduction hub.
  1. Install the shift rail.
  1. Install the oil pump, output shaft and the thrust washer.
  1. Install the magnet into its slot in the case.
  1. Install the drive chain and the sprockets as an assembly.
  1. Install the lockup hub assembly. If the lockup hub assembly was disassembled, carry out the following steps.
    1. Position the lockup collar.
    1. Install the lockup collar springs.
    1. Install the lockup hub.
    1. Install the armature.
    1. Install the lockup hub snap ring.
  1. Install the lockup hub and the shift fork and spring.
  1. Install the coil housing.
  1. Install the snap ring.
  1. Using the Mainshaft Bearing Installer, install the rear output shaft bearing.
  1. Using the Mainshaft Bearing Installer, install the front output shaft bearing.
  1. Install the transfer case field coil, washers and the 3 nuts.
    • Tighten to 10 Nm (89 lb-in).

  1. NOTE: Only apply enough silicone sealant to seal the transfer case halves together.

    Apply a small bead of silicone sealant to the mating surface of the case and cover.
  1. Position the 2 transfer case halves and tighten the 20 bolts in the sequence shown.
    • Tighten to 24 Nm (18 lb-ft).
  1. Using the Input Shaft Oil Seal Installer, install the rear output shaft seal.
  1. Apply a small bead of silicone sealant to the transfer case shift motor mating surface.

NOTICE: The following steps need to be performed in the correct order when installing the transfer case shift motor. Failure to follow the steps in the correct order may result in damage to the component.

  1. Install the transfer case shift motor and the 3 bolts.
    • Tighten to 10 Nm (89 lb-in).
  1. Install the transfer case shift motor bracket bolt.
    • Tighten to 10 Nm (89 lb-in).
  1. Secure the 2 transfer case shift motor bracket nuts.
    • Tighten to 3 Nm (27 lb-in).

  1. NOTE: After the coil wire is inserted into the connector, gently pull the wire back to verify the pin is locked inside the connector.

    Insert the coil wire pin in the electrical connector and install the inner connector retainer.
  1. Remove the transfer case from the Transmission Holding Fixture.
