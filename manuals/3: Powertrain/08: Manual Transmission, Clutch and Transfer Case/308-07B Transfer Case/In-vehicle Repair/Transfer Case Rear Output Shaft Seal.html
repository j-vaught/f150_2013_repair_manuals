308-07B Transfer Case 2013 F-150
In-vehicle Repair Procedure revision date: 08/30/2012

Transfer Case Rear Output Shaft Seal


Special Tool(s)
Installer, Input Shaft Oil Seal
308-249 (T96T-7127-A)


Item Part Number Description
1 46024602 Driveshaft
2 7B2157B215 Rear output shaft seal
3 7A1957A195 Transfer case

Removal

  1. With the vehicle in NEUTRAL, position it on a hoist. For additional information, refer to Section  100-02.
  1. Remove the rear driveshaft. For additional information, refer to Section  205-01.
  1. Using a suitable seal puller, remove the rear output shaft seal.

Installation

  1. Using the Input Shaft Oil Seal Installer, install the rear output shaft seal.
  1. Install the rear driveshaft. For additional information, refer to Section  205-01.
