303-04E Fuel Charging and Controls — Turbocharger 2013 F-150
Removal and Installation Procedure revision date: 04/24/2015

Turbocharger Coolant Return Tube — LH

Removal

  1. Remove the Coolant Crossover Manifold Assembly, refer to Section  303-03.

  1. NOTE: Use a 3/8" Jiffy-Tite® quick disconnect tool, close the tool around the tube, press the tool into the fitting and rotate until the tool is fully seated into the fitting.

    Disconnect the turbocharger coolant return tube at the turbocharger.
  1. Release the LH fuel injector connector retainers and the LH fuel injector harness retainer from the fuel rail. Position the LH fuel injector harness aside.
  1. Remove the turbocharger coolant return tube-to-cylinder head fitting from the cylinder head and remove the turbocharger coolant return tube.
  1. If necessary remove the retaining clip and then remove the turbocharger coolant return tube-to-cylinder head fitting.

Installation

  1. If removed, inspect the turbocharger coolant return tube-to-cylinder head fitting and replace as needed.
  1. If removed install the retaining clip and then install the turbocharger coolant return tube-to-cylinder head fitting.
  1. Install the turbocharger coolant return tube and then install the turbocharger coolant return tube-to-cylinder head fitting to the cylinder head. Tighten to 18 Nm (159 lb-in).
  1. Install the LH fuel injector connector retainers and the LH fuel injector harness retainer to the fuel rail.
  1. Inspect the turbocharger coolant tube-to-turbocharger fitting and replace as needed. Tighten to 18 Nm (159 lb-in).
  1. Connect the turbocharger coolant return tube at the turbocharger.
  1. Install the Coolant Crossover Manifold Assembly, refer to Section  303-03.
