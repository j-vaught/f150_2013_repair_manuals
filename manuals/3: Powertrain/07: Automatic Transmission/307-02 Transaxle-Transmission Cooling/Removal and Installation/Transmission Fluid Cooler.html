Removal

  1. Remove the transmission fluid cooler inlet hose from the transmission fluid cooler.
    • Discard the clamp.
  1. Remove the transmission fluid cooler outlet hose from the transmission fluid cooler.
    • Discard the clamp.
  1. Remove the transmission fluid cooler.

Installation

  1. Install the transmission fluid cooler.
  1. Install a new transmission fluid cooler outlet hose clamp.
  1. Install the transmission fluid cooler outlet hose to the transmission fluid cooler.
  1. Install a new transmission fluid cooler inlet hose clamp.
  1. Install the transmission fluid cooler inlet hose to the transmission fluid cooler.
  1. Fill the transmission with transmission fluid. For additional information, refer to Transmission Fluid Level Check in Section  307-01.
  1. Check for leaks.
