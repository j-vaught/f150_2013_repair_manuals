Removal

All vehicles

  1. With the vehicle in NEUTRAL, position it on a hoist. For additional information, refer to Section  100-02.

Rear Wheel Drive (RWD) vehicles

  1. Remove the rear driveshaft. For additional information, refer to Section  205-01.

  1. NOTE: The output shaft flange nut has been staked to prevent it from coming loose. Prior to removing the nut, remove the stake to prevent damage to the output shaft.

    Remove and discard the output shaft flange nut.
  1. Remove the extension housing flange seal and the output shaft flange.
  1. Using the Input Shaft Oil Seal Remover and Slide Hammer, remove the output shaft seal.

Four-Wheel Drive (4WD) vehicles

  1. Remove the transfer case. For additional information, refer to Section  308-07B.
  1. Using the Input Shaft Oil Seal Remover and Slide Hammer, remove the output shaft seal.

Installation

RWD vehicles

  1. Position a new output shaft seal.
  1. Using the Rear Seal 4X2 Installer, install the output shaft seal.
  1. Install the output shaft flange.
  1. Install the extension housing flange seal and a new output shaft flange nut.
    • Tighten to 80 Nm (59 lb-ft).
    • After installing the new output shaft flange nut, it must be staked at the slots to prevent it from coming loose.
  1. Install the rear driveshaft. For additional information, refer to Section  205-01.

4WD vehicles

  1. Install the seal protector provided with the new output shaft seal on the output shaft.
  1. Slide the output shaft seal over the output shaft seal protector onto the output shaft. Remove the output shaft seal protector.
  1. Using the Rear Seal 4X4 Installer, install a new output shaft seal.
  1. Install the transfer case. For additional information, refer to Section  308-07B.

All vehicles

  1. Fill and check the transmission fluid. For additional information, refer to Transmission Fluid Level Check in this section.
