Assembly

  1. Position the forward clutch assembly in the Clutch End Play Gauge and install the overdrive clutch pack onto the forward clutch and planetary gear set.
  1. Install the intermediate shaft assembly.

  1. NOTE: Inspect and install new thrust bearings as required.

    Install the T4 intermediate shaft bearing.
  1. Install the forward clutch hub and sun shaft assembly.
  1. Install a new the direct clutch hub.

  1. NOTICE: Do not install the snap ring on the forward clutch hub with the snap ring gap in the same position as the original snap ring or damage to the transmission can occur.

    Install a new direct clutch outer shell retaining ring with the snap ring gap positioned approximately 120 degrees from the index mark made on the forward clutch hub during disassembly.
    1. New snap ring gap
    1. Index mark from original snap ring gap
