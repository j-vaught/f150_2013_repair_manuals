501-10 Seating 2013 F-150
Description and Operation Procedure revision date: 08/30/2012

Seating

Front Seats

Front Bucket Seats

NOTE: For component identification and locations, refer to Seat — Exploded View, Front in this section.

The front bucket seats can be equipped with the following serviceable items:

  • Adjustable head restraint and guide sleeves attached to the backrest frame
  • Backrest and cushion covers
  • Backrest and cushion foam pads
  • Backrest frames (equipped with manual and power recliners) attached to the seat track
  • Climate controlled seat system components (heated/cooled seats)
  • Cushion side shield attached to the outboard side of the seat cushion frames
  • Heated seat system
  • Manual adjustable lumbar assembly attached to the backrest and seat track
  • Manual and power seat tracks located at the seat base (includes cushion frame)
  • Memory system components attached to the driver seat
  • Occupant Classification System (OCS) system on passenger seat
  • Power adjustable lumbar assembly attached to the backrest frame
  • Power recliner motor attached to the backrest frames
  • Safety belt buckle attached to the seat track
  • Seat control switches attached to the cushion side shield inserts
  • Seat side air bag attached to the seat backrest frames
  • Seat track position sensor attached to driver seat track (part of the Supplemental Restraint System (SRS) )

Driver Seat Module (DSM) — Memory Seat

The driver power seat is controlled by the DSM . The DSM is located on the driver seat track.

This system allows automatic positioning of the driver seat to 2 programmable positions. For information on programming memory positions or recalling a stored memory position, refer to Memory Position Programming in this section.

Memory Recall — Remote Keyless Entry (RKE)

When the vehicle is equipped with a memory driver seat, the RKE can be used with a key that includes an Integrated Keyhead Transmitter (IKT) . A personality or memory position for the driver seat and exterior rear view mirrors can be assigned to an IKT . Up to 2 personalities can be assigned, 1 per IKT . If the remote IKT has been associated to a memory position, pushing IKT unlock button recalls the memory seat and exterior rear view mirror positions.

For information on diagnosing a RKE concern or associating an IKT to a memory position, refer to Section  501-14.

Easy Entry/Exit

The easy entry/exit feature is a function of the DSM . The memory driver seat easy entry/exit feature moves the seat slightly rearward for easier exit from the vehicle and returns the seat forward after entry. The easy entry/exit feature can be enabled/disabled using the selections on the message center. For additional information on how to enable/disable the easy entry/exit feature, refer to the Owner's Literature or Section  413-01 for information on the message center.

Heated Seats — Front

This system allows independent seat electrical heating of the driver and front passenger seats on demand.

The heated seat system includes the following serviceable components:

  • Heater mats attached to the seat backrest and cushion foam pads
  • Front Display Interface Module (FDIM) (touchscreen)
  • HVAC module

Climate Controlled Seats

The climate control seat system is able to heat and cool the driver and front passenger seats. Each climate controlled seat is operated by push-buttons on the Front Display Interface Module (FDIM) located on the instrument panel. Each front seat temperature is then monitored and controlled by the Dual Climate Controlled Seat Module (DCSM) located on the passenger front seat track.

The climate controlled seat system contains the following serviceable components:

  • Air filter (attached to each Thermo-Electric Device (TED) and blower assembly) (See the Owner's Literature for additional service and scheduled maintenance interval information)
  • Cushion and backrest foam pads
  • Cushion and backrest manifolds
  • DCSM attached to the passenger seat track
  • Front Display Interface Module (FDIM)
  • HVAC module
  • TED and blower assembly within each front seat cushion and backrest
  • Ventilated cushion and backrest trim covers

Remote Start Climate Operation (If Equipped With Heated Or Climate Controlled Seats)

The customer can select different climate control modes/preferences when the vehicle is started using the remote start feature. This can be accessed through the message center. For information on how to set the remote start preferences, refer to the Owner's Literature. When the driver seat and/or passenger seat is set to AUTO mode, the driver/passenger heated/climate controlled seat activates in full heat mode when the outside temperature is less than 0°C (32°F) and full cool mode (climate controlled seats only) when outside temperature is greater than 27°C (80°F) any time the vehicle is started using the remote start feature. No heated/climate controlled seat adjustments are recognized during remote start operation. When the ignition is cycled to the ON position after a remote start event, the heated/climate controlled seat switches off.

Front Seat Track Motor

There are 3 front seat track motors present on power seat tracks. The horizontal (fore/aft) front seat track motor is the only seat track motor which can be serviced separately from the seat track assembly. All other seat track motors (front up/down, rear up/down) are serviced as part of the seat track assembly.

Front Seat Motor Cable

The horizontal (fore/aft) front seat track motor rotates 2 cables which drive each side of the seat track uniformly. The outboard (long) cable can be serviced separately from the horizontal front seat track motor.

Manual Lumbar

The manual front seat backrest lumbar is adjusted by a knob attached at the side of the seat cushion side shield. The lumbar adjuster is mounted to the seat track assembly and drives a cable connected to the lumbar assembly attached to the backrest frame.

Power Lumbar

The lumbar switch is attached to the cushion side shield insert and is part of the seat control switch. The lumbar motor is mounted to the lumbar assembly and is serviced only with a new lumbar assembly.

Manual Recliner

The manual recliner can be adjusted by a handle mounted on the outboard side of the cushion side shield. Manual recliners are only serviceable by installing a new backrest frame assembly.

Power Recliner

The power recliner switch is part of the seat control switch attached to the seat cushion side shield insert. The power recliner motor can be serviced separately but the power recliner assembly is serviceable only with a new backrest frame.

Occupant Classification System (OCS) System

The OCS system is standard equipment on all front outboard passenger seats. For information on diagnosing or servicing the OCS system, refer to Section  501-20B.

Front Center Seat

Front center seat can be equipped with the following serviceable items:

  • Backrest cover (without backrest storage)
  • Backrest latch and latch cover attached to the RH side of the backrest and seat frame
  • Cushion cover
  • Cushion latch release handle
  • Front and rear cup holders
  • Front and rear storage trays attached to the seat frame
  • LH and RH side shields attached to the seat frame
  • Power Point and wiring attached to the rear cup holder and seat frame
  • Safety belt buckle attached to the seat frame
  • Seat frame
  • Storage tray (in seat frame under cushion) (if equipped)

The front center seat is mounted to a pedestal under the carpet. Pedestal removal is not required for seat removal. The pedestal is also used for floor console mounting when not equipped with a front center seat. The pedestal is equipped with press fit spacers and washers above and below to prevent corrosion of body and seat structures. If removed, any of these items that become separated from the pedestal during service must be reinstalled to prevent corrosion damage that may compromise structural integrity of the body and seats.

Rear Seats — SuperCab

The SuperCab rear seat is equipped with a non-folding bench style backrest mounted to the rear cab panel and seat cushion frame and a 40/60 split folding cushion attached to the floor.

The SuperCab rear seat can be equipped with the following serviceable items:

  • Adjustable head restraints and head restraint covers
  • Backrest and cushion covers
  • Backrest and cushion foam pads
  • Backrest, cushion and seat frames
  • Backrest latches attached to the seat frame
  • Backrest upper clips attached to the backrest frame
  • Cushion latches, latch bolt covers and release handles
  • Head restraint guide sleeves attached to the backrest frame
  • Inboard and outboard seat risers
  • Non-serviceable lower anchors and tethers for children welded to the seat frame

Rear Seats — Crew Cab

The Crew Cab rear seat is a 40/60 split bench style with folding cushions and optional folding armrest with cup holder. The backrests are fixed to the rear cab panel by latches that can be accessed from behind only for service allowing the backrest to fold down. The backrest latches are accessible only when the seat cushion is folded upright.

The Crew Cab rear seat can be equipped with the following serviceable items:

  • Accessory hooks attached to the bottom of each cushion
  • Adjustable head restraints and head restraint covers
  • Armrest, backrest and cushion covers
  • Armrest, backrest and cushion foam pads
  • Armrest, backrest, cushion and seat frames
  • Backrest latch attached to each backrest frame
  • Backrest latch strikers attached to the rear cab panel
  • Cup holder attached to the armrest frame
  • Cushion latches attached to the cushion frame and outboard risers
  • Cushion release handle and bezel attached to the bottom of each cushion frame (includes release cable)
  • Head restraint guide sleeves attached to the backrest frames
  • Heated seat system
  • Inboard and outboard seat risers
  • Inboard and outboard side shields attached to the seat risers
  • Non-serviceable lower anchors and tethers for children welded to the seat cushion frames
  • Safety belt buckle attached to each inboard seat riser

Heated Seats — Rear

This system allows independent seat electrical heating of the 40 percent and outboard 60 percent seat positions on demand.

The heated seat system includes the following serviceable components:

  • Heater mats attached to the seat backrest and cushion foam pads
  • Heated seat module attached behind the 60 percent seat backrest
  • Heated seat switches attached to the rear door power window switch bezels
  • Wire harness attached to the base of each backrest frame
