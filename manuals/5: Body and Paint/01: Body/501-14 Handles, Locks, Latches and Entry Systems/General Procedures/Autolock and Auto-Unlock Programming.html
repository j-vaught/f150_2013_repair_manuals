501-14 Handles, Locks, Latches and Entry Systems 2013 F-150
General Procedures Procedure revision date: 08/30/2012

Autolock and Auto-Unlock Programming

Programming the Autolock Feature Using the Door Lock Control Switch

NOTE: The autolock feature can also be programmed using the message center.

NOTE: The autolock feature can be activated or deactivated independently of the auto-unlock feature.

NOTE: When programming the autolock feature using the door lock control switch method, the following steps must be carried out within 30 seconds or the procedure will need to be repeated. If the procedure needs to be repeated, wait 30 seconds between programming sessions.

  1. NOTE: Prior to beginning, make sure the ignition key is in the OFF position and all vehicle doors are closed.

    Turn the ignition key from the OFF to the ON position.
  1. Press the unlock button on the door lock control switch 3 times.
  1. Turn the ignition key from the ON to the OFF position.
  1. Press the unlock button on the door lock control switch 3 times.
  1. Turn the ignition key to the ON position. The horn chirps once to indicate that programming mode is entered.
  1. To enable/disable the autolock feature, press the unlock button on the door lock control switch, then the lock button. The horn chirps once if the autolocks are disabled or twice (one short chirp followed by a long chirp) if the autolocks are enabled.
  1. Turn the ignition key to the OFF position. The horn chirps once to signal that the programming is complete.

Programming the Autolock Feature Using the Keyless Entry Keypad

NOTE: The autolock feature can also be programmed using the message center.

NOTE: The autolock feature can be activated or deactivated independently of the auto-unlock feature.

  1. Turn the ignition key to the OFF position and close all vehicle doors.
  1. Enter the permanent factory keyless entry keypad code.
  1. Press and hold the 3/4 button on the keypad. While holding the 3/4 button, press the 7/8 button.
  1. Release the 7/8 button, then release the 3/4 button. The horn chirps once if the autolocks are disabled or twice (one short chirp followed by a honk) if the autolocks are enabled.

Programming the Auto-Unlock Feature Using the Door Lock Control Switch

NOTE: The auto-unlock feature can also be programmed using the message center.

NOTE: The auto-unlock feature can be activated or deactivated independently of the autolock feature.

NOTE: When programming the auto-unlock feature using the door lock control switch method, the following steps must be carried out within 30 seconds or the procedure will need to be repeated. If the procedure needs to be repeated, wait 30 seconds between programming sessions.

  1. NOTE: Prior to beginning, make sure the ignition key is in the OFF position and all vehicle doors are closed.

    Turn the ignition key from the OFF to the ON position.
  1. Press the unlock button on the door lock control switch 3 times.
  1. Turn the ignition key from the ON to the OFF position.
  1. Press the unlock button on the door lock control switch 3 times.
  1. Turn the ignition key to the ON position. The horn chirps once to indicate that programming mode is entered.
  1. To enable/disable the auto-unlock feature, press the lock button on the door lock control switch, then the unlock button. The horn chirps once if auto-unlock is disabled or twice (one short chirp followed by a long chirp) if auto-unlock is enabled.
  1. Turn the ignition key to the OFF position. The horn chirps once to signal that the programming is complete.

Programming the Auto-Unlock Feature Using the Keyless Entry Keypad

NOTE: The auto-unlock feature can also be programmed using the message center.

NOTE: The auto-unlock feature can be activated or deactivated independently of the autolock feature.

  1. Turn the ignition key to the OFF position and close all vehicle doors.
  1. Enter the permanent factory keyless entry keypad code.
  1. Press and hold the 3/4 button on the keypad. While holding the 3/4 button, press and release the 7/8 button. While still holding the 3/4 button, press and release the 7/8 button a second time.
  1. Release the 3/4 button. The horn chirps once if auto-unlock is disabled or twice (one short chirp followed by a honk) if auto-unlock is enabled.
