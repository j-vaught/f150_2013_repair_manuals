501-14 Handles, Locks, Latches and Entry Systems 2013 F-150
General Procedures Procedure revision date: 08/30/2012

Remote Memory Deactivation

  1. Press the set button on the memory set switch.
  1. Within 5 seconds, press any button on the Remote Keyless Entry (RKE) transmitter that you wish to deactivate and then press the set button on the memory set switch.
  1. If a second memory setting is desired to be deactivated, repeat the procedure with the second RKE transmitter.
