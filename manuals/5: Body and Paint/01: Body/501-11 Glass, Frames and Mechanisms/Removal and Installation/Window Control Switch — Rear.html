Window Control Switch — Rear

NOTE: LH shown, RH similar.


Item Part Number Description
1 1452814528 RH/ 14527 LH RH/ 14527 LH Window control switch bezel
2 — Window control switch bezel clips (part of window control switch bezel) (2 required)
3 — Window control switch electrical connector
4 1452914529 Window control switch

Removal and Installation

  1. Using a suitable trim tool, release the 2 clips on the outer edge of the window control switch bezel and pull the window control switch assembly straight upward.
  1. Disconnect the window control switch electrical connector.
  1. Release the tabs and remove the window control switch from the bezel.
  1. To install, reverse the removal procedure.
