501-11 Glass, Frames and Mechanisms 2013 F-150
Removal and Installation Procedure revision date: 08/30/2012

Window Glass — Front Door

Removal

NOTE: The front window motor must be de-initialized, then initialized whenever the LH front or RH front window motor is removed from the window regulator drum housing, a new window regulator is installed, a new window glass is installed, a new top run is installed or for any operation in which grease or lubricants are applied to the window regulator or glass run.

With power windows

  1. Remove the window control switch. For additional information, refer to Window Control Switch — Front in this section.

All vehicles

  1. Remove the front door trim panel. For additional information, refer to Section  501-05.
  1. Remove the front door interior moulding.
  1. If equipped, remove the bolster assembly.
    • Remove the bolt and 2 pin-type retainers.
  1. Position aside the front door watershield.
  1. Remove the 2 front door below belt bracket bolts and bracket.
    • If equipped, disconnect the electrical wiring harness pushpin.
  1. Temporarily install the window control switch or the window crank to raise or lower the window as necessary to access the glass-to-regulator assembly bolts.
  1. Loosen the 2 front door window glass-to-regulator assembly bolts.
  1. Tape the window in position, then lower the front door window regulator to the full downward position.

  1. NOTE: The top run may be positioned aside to gain additional clearance if needed.

    Tip the front of the glass down and pull the front door window glass out through the top outboard side of the door.

Installation

All vehicles

  1. Install the glass into the door and tape in place.
    • Reposition the top run if it was positioned aside during the glass removal.
  1. Temporarily install the window control switch or the window crank to raise or lower the regulator as necessary to access the glass-to-regulator assembly bolts.

  1. NOTE: It is important that this step is performed to prevent a customer concern of slow power window travel when raising the window.

    Push the glass up into the header by hand, then shift the glass rearward until it stops against the rear window run seal while lowering the glass back down into the window glass clamps.

  1. NOTE: Make sure the window glass is seated in the bottom of the glass clamps.

    Tighten the 2 front door window glass-to-regulator assembly bolts to 11 Nm (97 lb-in).
  1. Install the 2 front door below belt bracket bolts and bracket.
    • Tighten to 11 Nm (97 lb-in).
  1. Install the front door watershield.
  1. If equipped, install the bolster assembly.
    • Tighten the bolt and install the 2 pin-type retainers.
  1. Install the front door interior moulding.
  1. Install the front door trim panel. For additional information, refer to Section  501-05.

With power windows

  1. Install the window control switch. For additional information, refer to Window Control Switch — Front in this section.
    • Initialized the front window motor. For additional information, refer to Window Motor Initialization in this section.
