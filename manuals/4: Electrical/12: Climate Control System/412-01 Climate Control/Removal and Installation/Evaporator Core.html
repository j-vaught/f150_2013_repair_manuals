412-01 Climate Control 2013 F-150
Removal and Installation Procedure revision date: 08/30/2012

Evaporator Core

Removal

NOTE: If an evaporator core leak is suspected, the evaporator core must be vacuum leak tested before it is removed from the vehicle.

NOTE: The evaporator core is available only as part of the heater core and evaporator core housing assembly.

  1. Remove the heater core and evaporator core housing. Refer to Heater Core And Evaporator Core Housing.
  1. Transfer the components from the old housing to the new housing as needed.

Installation

  1. To install, reverse the removal procedure.
