415-00B Information and Entertainment Systems — AM/FM/CD 2013 F-150
Removal and Installation Procedure revision date: 08/30/2012

Audio Input Jack

NOTE: Vehicle with the SYNC® system shown, others similar.


Item Part Number Description
1 19C14919C149 Audio input jack bezel
2 — Audio input jack electrical connector (part of 14401)
3 19A16419A164 Audio input jack

Removal and Installation

  1. Using a suitable tool such as a hook-shaped pick, remove the audio input jack bezel by prying rearward.
    • Disconnect the electrical connector(s).
  1. Release the tabs and remove the audio input jack.
  1. To install, reverse the removal procedure.
