415-00C Information and Entertainment Systems — 4.2-Inch (107 mm) Display 2013 F-150
Removal and Installation Procedure revision date: 06/20/2013

Front Controls/Display Interface Module (FCDIM)

Removal and Installation

  1. NOTE: If installing a new module, it is necessary to upload the module configuration information to the scan tool prior to removing the module. This information must be downloaded into the new module after installation.

    Upload the Front Control/Display Interface Module (FCDIM) configuration information to the scan tool by following the scan tool on screen instructions.
  1. Remove the Front Controls Interface Module (FCIM) . Refer to Section  415-00C.
  1. Remove the 4 screws and remove the Front Control/Display Interface Module (FCDIM) .
    • Disconnect the electrical connector.
    • To install, tighten to 2.5 Nm (23 lb-in).
  1. To install, reverse the removal procedure.
  1. Download the Front Control/Display Interface Module (FCDIM) configuration information from the scan tool to the new Front Control/Display Interface Module (FCDIM) following the scan tool on screen instructions.
