Overview

Ford Work Solutions™ Crew Chief package consists of the following:

  • Telematics module
  • Modem-antenna
  • Crew Chief harness

System Operation

System Diagram

Crew Chief

Crew Chief is a web-based application used to view vehicle data, create reports, and monitor real-time alerts.

Component Description

Modem-Antenna

The modem-antenna contains a CDMA (Code Division Multiple Access) modem and a GPS antenna.

The CDMA (Code Division Multiple Access) modem receives vehicle information from the telematics module and transmits this data via a mobile phone network to a server, where it can be accessed through a secure website.

The GPS antenna is used to determine the vehicle’s location. The GPS information is processed and sent to the telematics module.

Telematics Module

The telematics module can be operated with the ignition in ON/RUN, ACC, or OFF.

The telematics module does not communicate with a diagnostic scan tool.

All information collected by the telematics module is transmitted to the CDMA (Code Division Multiple Access) modem contained within the modem-antenna.

The telematics module reads and requests vehicle information by communicating with other vehicle modules through the HS-CAN . The telematics module may collect or calculate vehicle information such as:

  • Airbag indicator status
  • Battery voltage
  • Driver seatbelt status
  • DTCs
  • Engine coolant temperature
  • Engine speed
  • Fuel level
  • Fuel used
  • Harsh acceleration occurrences
  • Harsh braking occurrences
  • Idle time
  • MIL status
  • Odometer reading
  • Oil life status
  • Throttle position
  • TPMS indicator status
  • Vehicle location
  • Vehicle speed

Some vehicle information can be collected and transmitted to the modem-antenna with the ignition in ACC, but the majority requires the ignition to be in ON/RUN in order to be collected and transmitted. With the ignition in ON/RUN, the telematics module packages and transmits a message approximately every 3 minutes, except for special instances which are transmitted per occurrence, such as harsh braking or an airbag deployment. With the ignition in OFF, the telematics module transmits a message approximately every 12 hours to indicate the vehicle location and that contact is being maintained between the telematics module and server.

The telematics module receives GPS information from the GPS antenna. The GPS information is packaged with collected vehicle information in order to associate a vehicle location with the collected vehicle information.

In addition to transmitting information, the telematics module receives information from the modem-antenna such as vehicle location and over-the-air firmware updates.
