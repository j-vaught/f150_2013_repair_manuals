413-13 Parking Aid 2013 F-150
Removal and Installation Procedure revision date: 08/30/2012

Parking Aid Sensor


Item Part Number Description
1 — Parking aid sensor bezel
2 15K85915K859 Parking aid sensor
3 — Parking aid sensor electrical connector (part of 13A576)

Removal

  1. Disconnect the parking aid sensor electrical connector.
  1. Using a suitable tool (such as a flat-bladed screwdriver), carefully pry away the retaining tabs to remove the parking aid sensor from the sensor bezel.
    • Remove the parking aid sensor from the rear bumper.

Installation

  1. To install the parking aid sensor in the rear bumper, insert the sensor in the sensor bezel opening until the retaining tabs lock in position.
  1. Connect the parking aid sensor electrical connector.
  1. After installing the sensor(s), use the scan tool to verify that the parking aid sensor PIDs read no object present.
  1. Carry out the azimuth and elevation test. For additional information, refer to Azimuth System Check and Elevation System Check in this section
