419-01B Anti-Theft — Passive Anti-Theft System (PATS) 2013 F-150
General Procedures Procedure revision date: 08/30/2012

Key Programming — Unlimited Key Mode


Special Tool(s)
Vehicle Communication Module (VCM) and Integrated Diagnostic System (IDS) software with appropriate hardware, or equivalent scan tool

Enabling Unlimited Key Mode

NOTE: When in the unlimited key mode, the KEYS_PROGMD PID in the Body Control Module (BCM) always reads 2, no matter how many keys are programmed to the vehicle (after the first 2 keys have been programmed to the vehicle).

NOTE: If the BCM PID UNL_KEY_ID is not available, unlimited key mode is turned on, and must be turned off before viewing the stored code. At this time, unlimited keys may be programmed to the vehicle. To view/disable/change the stored code, follow the procedure below for disabling the unlimited key mode.

  1. The customer must choose an 8-digit number (except for 00000000, 00000001, or FFFFFFFF) to be programmed to all of their vehicles or, to all of the keys for one vehicle. Valid digits are 0-9 and the letters A-F.
  1. From the scan tool, enter TOOLBOX. Select BODY — SECURITY — PATS Functions and follow the Integrated Diagnostic System (IDS) on-screen instructions to ENTER SECURITY ACCESS.
  1. Once in security access, select "unlimited key mode ON" and follow the IDS on-screen instructions.
  1. Select "program unlimited key code" and follow the IDS on-screen instructions. Enter the 8-digit code chosen by the customer in Step 1 of this procedure and follow the IDS on-screen instructions.
  1. Select "Ignition Key Code Erase" and follow the IDS on-screen instructions.
  1. Turn the key to the OFF position and disconnect the scan tool (the key does not need to be removed from the ignition at this time).
  1. Turn the first PATS key to the RUN position for a minimum of 6 seconds.
  1. Turn the first PATS key to the OFF position and remove the key from the ignition.
  1. Insert the second PATS key into the ignition and turn the key to the RUN position for a minimum of 6 seconds.
  1. The engine should now start with both PATS keys.
  1. If it is desired to program additional key(s), refer to Key Programming — Program a Key Using Two Programmed Keys in this section.

Disabling Unlimited Key Mode

  1. From the scan tool, enter TOOLBOX. Select BODY — SECURITY — PATS Functions and follow the IDS on-screen instructions to ENTER SECURITY ACCESS.
  1. Select "unlimited key mode OFF" and follow the IDS on-screen instructions.
  1. Select "Ignition Key Code Erase" and follow the IDS on-screen instructions.
  1. Turn the key to the OFF position and disconnect the scan tool (the key does not need to be removed from the ignition at this time).
  1. Turn the first PATS key to the RUN position for a minimum of 6 seconds.
  1. Turn the first PATS key to the OFF position and remove the key from the ignition.
  1. Insert the second PATS key into the ignition and turn the key to the RUN position for a minimum of 6 seconds.
  1. The engine should now start with both PATS keys.
  1. If it is desired to program additional key(s) (only a total of 8 keys can be programmed into the BCM ), refer to Key Programming — Program a Key Using Two Programmed Keys in this section.
