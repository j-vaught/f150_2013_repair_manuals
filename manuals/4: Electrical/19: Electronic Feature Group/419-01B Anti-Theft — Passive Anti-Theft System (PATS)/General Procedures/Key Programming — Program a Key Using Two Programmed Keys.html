419-01B Anti-Theft — Passive Anti-Theft System (PATS) 2013 F-150
General Procedures Procedure revision date: 08/30/2012

Key Programming — Program a Key Using Two Programmed Keys

NOTE: This procedure works only if 2 or more programmed keys are available. If 2 programmed keys are not available, refer to Key Programming Using Diagnostic Equipment in this section.

NOTE: This procedure works only if the customer spare key programming is enabled. If customer spare key programming is disabled, refer to Key Programming — Enable/Disable Spare Key Programming or Key Programming Using Diagnostic Equipment in this section.

  1. Insert the first programmed Passive Anti-Theft System (PATS) key into the ignition and turn the key from the OFF position to the RUN position (maintain the key in the RUN position for approximately 6 seconds).
  1. Turn the first key to the OFF position and remove the key from the ignition.
  1. Within 10 seconds of turning the key to the OFF position, insert a second programmed PATS key into the ignition and turn the key from the OFF position to the RUN position (maintain the key in the RUN position for approximately 6 seconds).
  1. Turn the second key to the OFF position and remove the key from the ignition.

  1. NOTE: The doors lock and then unlock to confirm that each Integrated Keyhead Transmitter (IKT) is programmed.

    Within 10 seconds of turning the second key to the OFF position, insert the new, unprogrammed PATS key into the ignition and turn the key from the OFF position to the RUN position (maintain the key in the RUN position for approximately 6 seconds).
  1. If it is desired to program additional key(s) (up to a total of 8 keys can be programmed), repeat Steps 1 - 5 for each additional key.
