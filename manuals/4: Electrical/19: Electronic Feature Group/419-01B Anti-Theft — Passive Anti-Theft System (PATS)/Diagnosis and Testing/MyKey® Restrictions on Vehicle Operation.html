MyKey® Restrictions on Vehicle Operation

Principles of Operation

The MyKey® feature allows a restricted driving mode to be programmed into one (or more) key(s) supplied with the vehicle or into any (Passive Anti-Theft System (PATS) ) programmed spare key(s) to promote good driving habits. The MyKey® is a restricted key for all consecutive key cycles until the MyKey® restricted key is cleared. The remaining key(s) is referred to as an administrator key(s) or admin key(s). There must always be at least one admin key. The Body Control Module (BCM) does not allow the last administrator key to be programmed as a MyKey® restricted key. Both the admin key and the MyKey® can be used to see how many admin keys and MyKey® restricted keys are programmed to the vehicle, and how many total miles have been driven with the MyKey® active.

When the MyKey® feature is programmed, several features are modified for the MyKey® driver only.

Inspection and Verification

  1. Verify the customer concern.
  1. If an obvious cause for an observed or reported concern is found, correct the cause (if possible) before proceeding to the next step.
  1. If the cause is not visually evident, verify the symptom. GO to Symptom Chart.
