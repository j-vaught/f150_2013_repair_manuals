211-05 Steering Column Switches 2013 F-150
Description and Operation Procedure revision date: 08/30/2012

Steering Column Switches

The steering column switches consist of the following components:

  • Steering Column Control Module (SCCM)
  • Ignition switch
  • Hazard flasher switch
  • Multifunction switch
  • Brake pedal control switch (if equipped)
  • Steering column control switch (if equipped)
  • Steering wheel switches (if equipped)
  • Steering wheel rotation sensor (if equipped)

Steering Column Control Module (SCCM)

The SCCM acts as a central hub for the steering column switches and circuits. The hazard flasher switch, multifunction switch, brake pedal control switch and steering column control switch are mounted directly to the SCCM and can be serviced separately from the SCCM .
