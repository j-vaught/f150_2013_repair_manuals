206-09 Anti-Lock Brake System (ABS) and Stability Control 2013 F-150
Removal and Installation Procedure revision date: 02/20/2013

Steering Wheel Rotation Sensor


Item Part Number Description
1 3F8183F818 Steering wheel rotation sensor

Removal

NOTE: Only available on the 6.2L engine. For all other applications, the sensor is part of the Electronic Power Assist Steering (EPAS ) and is not serviced seperatley.

  1. Remove the clockspring. For additional information, refer to Section  501-20B.
  1. Remove the steering wheel rotation sensor.

Installation

  1. Align the arrow on the inner ring of the sensor to the notch on the sensor body.
  1. Position the sensor on the Steering Column Control Module (SCCM).
  1. Install the clockspring. For additional information, refer to Section  501-20B.
