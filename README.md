# 2013 Ford F-150 Repair Manuals

Private personal archive of workshop information and wiring documentation for a 2013 Ford F-150.

The `manuals` directory contains workshop procedures in HTML and PDF, wiring diagrams in SVG and PDF, component-location views, table-of-contents metadata, and connector-location data. The archive contains 3,481 files and was retrieved using an authorized Ford service-information subscription.

Ford's current connector-face endpoint redirects to a dealer-only sign-in. Those connector-face PDFs are therefore not present. The 439-entry connector index and the 1,432-row connector-to-diagram location lookup are included.

This repository is intended only for the vehicle owner's private reference. Ford publications remain the property of their respective copyright holders and are not licensed for redistribution by this repository.

No subscription cookies, passwords, payment information, or other account credentials are stored here.
